# Better Brand Services

## Builder email verification

The AI Builder uses a server-verified four-digit code while keeping the authenticated session in Netlify Identity. In the Netlify Identity email settings, set the confirmation template URL to `/auth-emails/confirmation.html` and the recovery template URL to `/auth-emails/recovery.html` on the deployed site. These templates display the short code generated by the builder authentication function.

A premium, responsive digital agency website for **Better Brand Services** and `betterbrandservices.com`. The site presents logo design, brand images, video editing, website design, and complete branding packages in a conversion-focused single-page experience.

## Technology

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Tailwind CSS 4 with a custom global design system
- Lucide icons
- Netlify Forms for inquiry capture and spam protection
- Netlify deployment through the TanStack Start adapter

## Features

- Custom compact BBS logo and favicon
- Responsive navigation and mobile menu
- Animated hero, service cards, work showcase, pricing, delivery times, about, FAQ, and contact sections
- Interactive service detail modal
- Fixed WhatsApp chat button for `+1 (408) 461-1901`
- Validated contact form with success and error states
- SEO metadata and canonical domain configuration
- Reduced-motion accessibility support

## Local Development

Install dependencies and start the local Netlify development environment:

```bash
npm install
netlify dev --port 8889
```

The site is then available through the URL printed by Netlify Dev.

## Contact Form

The contact form posts to Netlify Forms through `public/__forms.html`. Form submissions appear under the project’s Forms area in Netlify. To receive each inquiry by email, add a form submission email notification under **Project configuration → Notifications → Emails and webhooks** and select the `better-brand-contact` form.
